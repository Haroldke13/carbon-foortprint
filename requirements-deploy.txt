# Production dependency set for the container build.
#
# The repo's requirements.txt is left untouched, but it is a `pip freeze` of a
# virtualenv that was shared with the stock-market project. It pins yfinance,
# scikit-learn, statsmodels, plotly, matplotlib, numpy, pandas, scipy,
# beautifulsoup4, lxml, html5lib, peewee, pillow, joblib, patsy and friends.
#
# Not one of those is imported anywhere in this codebase (checked against every
# import statement in app.py, config.py and app/*.py). They add roughly 700 MB
# to the image and a large amount of CVE surface for nothing.
#
# What the code actually imports:
#   flask, flask_sqlalchemy, flask_login, flask_bcrypt, flask_migrate,
#   flask_wtf, flask_cors, wtforms (+ Email -> email-validator), werkzeug,
#   stripe, paypalrestsdk, requests
